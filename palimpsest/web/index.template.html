Palimpsest Playground

A self-rewriting term-rewriting language, running entirely in your browser: the interpreter is a Python port of the Rust reference implementation, executed by Pyodide. Output, fuel counts included, matches the native binary.

How it works
  • Pick a program, edit it if you like, and press Run (or Ctrl/⌘ + Enter). The options mirror the command line: --dry-run, --memo, --stats, --trace N, --fuel N.
  • The repository's files live in a virtual file system, so import "../lib/prelude.pal" works as it does locally. A program that runs rewrite self rewrites its file there; the editor shows the new text, Undo restores the previous version from the ledger, and Reset reloads the original.
  • Your edits are kept in this browser only. Download saves the current file; Open… loads a .pal file from your computer.
  • Programs run about 15× slower than the native Rust binary. Heavy studies (marked with their native run time) can take minutes; Stop ends a run at any time.
